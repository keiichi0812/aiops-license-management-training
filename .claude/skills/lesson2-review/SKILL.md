# 第2回のレビュー

レビュー対象：$ARGUMENTS

1. 対象ファイルを読み、目的と変更範囲を整理する。秘密ファイルは読まない。
2. 命名・型・本人範囲・日付境界のうち、対象に該当するものを点検する。
3. テストを実行した証拠がなければ「未実行」と書く。コードを読んだだけでテスト成功と書かない。
4. 「確認した事実」「指摘と根拠」「未確認・次の操作」の3つの見出しで日本語で報告する。
5. コード変更、コミット、pushは行わず、採用判断は本人に戻す。

このSkillは通常セッション内で動作し、サブエージェントは起動しない。
